# Security policy

A compliance and security project has to handle its own vulnerabilities carefully. Please report privately so a fix can ship before details are public.

## Reporting a vulnerability

Email security@verholm.com with:

- A description of the issue and its impact.
- Steps to reproduce.
- Affected versions or components, if known.

Do not open a public issue for a security problem.

## What to expect

- Acknowledgement within three working days.
- An initial assessment and severity within ten working days.
- Coordinated disclosure once a fix is available. Reporters are credited unless they ask not to be.

## Supported versions

While the project is pre-release, only the `main` branch receives security fixes. A support policy for tagged releases will be added once the project publishes releases.
