# Code of conduct

This project adopts the Contributor Covenant, version 2.1. The full text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In short: treat everyone with respect, assume good intent, and keep project
spaces free of harassment and personal attacks. We welcome contributors of all
backgrounds and experience levels.

## Reporting

Report unacceptable behavior privately to conduct@verholm.com. Reports are
handled confidentially. Maintainers who do not follow or enforce the code of
conduct may be removed from the project.
